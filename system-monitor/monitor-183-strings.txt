CMOVE    - move a disk file
CDISK    - check a disk name

CERASE   - erase a disk file
CCOPY    - copy disk files
CSYSTEM  - save system monitor

CCONSOLE - scan console inputs

CBOOT    - change the boot file
CANALYZE - analyze a song track
CMODEM   - communicate via modem
CUNERASE - recover erased files
CSPLIT   - split track into songs
