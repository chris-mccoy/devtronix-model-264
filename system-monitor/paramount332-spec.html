MIDI implementation

Hauptwerk's built-in MIDI recorder/player uses a completely fixed, prededfined MIDI implementation (for portability of MIDI files, independence of MIDI files from MIDI hardware/settings, independence of MIDI files from combination sets, touch-screen, mouse click and computer key compatibility, etc.).

To load a MIDI file in Hauptwerk's native MIDI recorder/player for this organ the file must use this fixed MIDI implementation.

The easiest way to create MIDI files with the appropriate implementation is simply to play live into Hauptwerk, while recording MIDI via its native MIDI recorder/player. You can then easily see or edit the appropriate events in the resulting MIDI file when the MIDI file is opened in an external sequencing program.

However, if you want to create or edit MIDI file events from scratch or by hand in your MIDI sequencer then this describes the implementation in detail.

Note that if you load a MIDI file into Hauptwerk's native MIDI player that was saved with a different virtual organ (sample set), then only the keys will play; registration changes and other controls recorded in the file will be ignored because in general there is no reliable way to map them automatically in a meaningful and artistic way between different organs.

Important: this MIDI implementation is intended for MIDI files and MIDI sequencers, and for this organ only. It isn't a requirement or recommendation for MIDI organ consoles/hardware in general.

Note that the combination system is usually bypassed on playback, with stop/coupler/tremulant registration changes instead being recorded and played back directly, hence virtual crescendo pedal movements are not sent or recorded directly. However, if you prefer you can enter general crescendo events manually in a MIDI sequencer project, rather than using individual stop/coupler/tremulant registration changes. If you choose to use these messages in your sequencer project then it will no longer be independent of combination sets and so cannot be exchanged so easily with other Hauptwerk users.

Also note that internal stop/coupler/tremulant registration changes resulting from 'blind' crescendo pedal movements might be recorded as MIDI sys-ex messages not listed in the table above.

MIDI sys-ex messages

MIDI note-on/off, MIDI NRPN and MIDI control change messages are used in preference for most virtual keyboards and controls, as covered above, since they are easy to view and edit in most MIDI sequencers.

However, since the MIDI standard allows for only a relatively small number of distinct messages of those types, Hauptwerk defaults to sending MIDI sys-ex messages as a last resort for virtual controls for which the sample set developer hasn't specified one of the standard 'role codes' (assignment codes) listed above. (Note that some sequencers ignore MIDI sys-ex messages from AU/VST plug-ins and that some virtual MIDI cable software doesn't work reliably with MIDI sys-ex messages.)

Please consult the Hauptwerk MIDI recorder/player fixed, predefined MIDI implementation section in the Hauptwerk user guide if you need the format used for the sys-ex messages.
